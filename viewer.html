先看画面，再下结论

选择文件和页码，后台生成可复查图片，无需打开桌面应用。支持 PDF、DOCX、PPTX、XLSX、图片、Markdown 和自包含 HTML。

首次使用：点右上角“怎么用”配置独立渲染引擎。不会自动安装依赖或打开前台窗口。

后台预览怎么用

1. 解压插件 ZIP，在根目录运行以下命令。需要 Docker Compose 和 Python 3；Windows 可使用命令提示符，无需 PowerShell。首次构建联网下载渲染依赖，预留约 3 GiB 磁盘和 1.5 GiB 运行内存。 

python3 scripts/setup-engine.py
docker compose -f engine/compose.yaml up --build -d

Windows 的 Python 命令通常是 python。setup 只生成本地私有令牌文件，不会修改 Aide。将 .file-preview-engine.env 里的 FILE_PREVIEW_TOKEN 值填入插件设置的 Renderer token；不要发到聊天中。

Docker Desktop Aide: http://host.docker.internal:18510
Native Aide: http://127.0.0.1:18510

2. 配好设置后重开工作台。选择已授权来源，浏览并选择文件；页码填 1 或 1,2，点后台渲染。下方会显示总页数、实际覆盖页、文件 SHA-256 和转换警告。

3. 局部放大填比例坐标，例如 0.5,0,0.5,0.5 表示右上四分之一。生成图片不等于完成视觉复查；需要支持 plugin-tool-images-v1 的 Aide 和真实视觉模型，才能让 AI 看图。旧宿主只能显示工作台图片和文字元数据。

HTML/Markdown 按打印样式渲染，禁用脚本、外部链接和相对资源。Office 转换可能与微软原生排版不同。插件不会自动覆盖或修复原文件。停止独立引擎： 

docker compose -f engine/compose.yaml stop
